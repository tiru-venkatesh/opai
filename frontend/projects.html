Hackathons & Programs

Before you register
  • Eligibility: student status, whether India can take part, age limits and team size.
  • Deadline time zone: IST, PST or EDT. The same date can fall on different days.
  • Whether the project must be newly built or can be an existing one you update.
  • Who owns the code and IP, and whether the repo must be public.
  • Whether you need an API key, a cloud account or a paid service. Skip events that need paid infrastructure unless credits are provided.
