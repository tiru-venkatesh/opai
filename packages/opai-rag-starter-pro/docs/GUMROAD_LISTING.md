## Long description
**Ship document Q&A that cites its sources.**

OPAI RAG Starter Pro takes the free, MIT-licensed Lite retrieval engine and adds what you need to put it in front of
customers.

**What you get**
- Postgres + pgvector store (HNSW index) and a ChromaDB adapter
- `opai-rag-eval`: measure hit@k, MRR and abstention on your own documents, compare chunk sizes, fail CI on regressions
- Multi-tenant HTTP API: one API key per customer, tenant isolation, rate limit, daily ask quota
- Dockerfile, docker-compose and a GitHub Actions workflow
- 30 tests, run against real Postgres and Chroma

**What it does not do:** no OCR, English-centric tokenizer, per-process rate limiting (daily quota is exact).
See the README's "Known limits".

**Requirements:** Python 3.10+ (tests run on 3.12); Postgres with the pgvector extension for the Postgres store.

**Try before you buy:** the Lite version is free on GitHub: <GITHUB_URL>

**Licence:** one developer, use in commercial products and hosted services, no redistribution of the source.
Full text in `LICENSE.txt` inside the download.
